# 우리집 가계부 · 주간 · 월간 · 연간 지출 내역 · 가계부 요약 · 식단 · 장보기

주간/월간/연간으로 넘겨 보는 **지출 내역**, **가계부 요약**(수입·지출·파킹·신용카드 청구 예정), 구매처별 **장보기 요약**, 그리고 식단 달력과 냉장고 재고를 한 페이지에서 보는 모바일용 HTML 한 장입니다.
빌드 도구도, 서버도, 외부 스크립트도 쓰지 않습니다. `index.html` 파일 하나로 동작합니다.

## 이 저장소에 들어 있는 것

- `index.html` — **빈 템플릿**입니다. 주문·재고·식단·가계부 같은 개인 데이터가 들어 있지 않고, 화면은 0원 · 0품목 · 0끼 상태로 열립니다.
- 데이터는 **이 저장소에 올리지 않습니다.** 각자 기기에서 아래 방법으로 불러오면 브라우저(localStorage)에만 저장됩니다.

## 기간 보기 (주간 · 월간 · 연간)

화면 위쪽의 `주간 | 월간 | 연간`으로 보기를 바꾸고, `◀` · `이번 주/이번 달/올해` · `▶`로 기간을 옮깁니다.

- **주간** — 월~일 7일 식단 카드, 주간 진행률, 주간 지표(구매액·재고·끼니·끼니당/1인당 평균 식대)
- **월간** — 월 달력(날짜마다 등록·완료 끼니 표시). 날짜를 누르면 그날 식단을 바로 확인·추가·수정·삭제할 수 있고, 월 구매액·소진비용·완료 끼니·끼니당 평균 식대와 카테고리별 지출이 함께 나옵니다.
- **연간** — 1~12월 월별 구매액·소진비용 막대 그래프와 연간 합계(총 구매비용·총 소진비용·완료 끼니·월 평균 식비)

가계부 탭·지출 내역 탭·장보기 요약 탭의 숫자도 위에서 고른 기간에 맞춰 다시 계산됩니다.

## 탭 구성 (아래쪽 5개 탭)

| 탭 | 내용 |
| --- | --- |
| 식단 달력 | 주간·월간·연간 식단, 끼니별 재료 사용량, 완료 시 재고 차감 |
| 냉장고 재고 | 총량·남은 양, 구매일·구매처·유통기한, 검색·카테고리·상태(보유만/소진만) 필터 |
| **지출 내역** | 건수 요약, 사람별 필터 칩(전체·나·배우자·공용), 개별 내역 카드(수정·삭제·배지), `+ 내역 추가` |
| **가계부** | 총 지출(파킹 제외)·사람별 합계·✏️ 이름, 총 수입, 저축·비상금 파킹, 순현금흐름, 카테고리별 지출, 이번 달 신카 청구 예정(카드별), 비상금 파킹 |
| 장보기 요약 | 구매처별 주문금액(기간 누적), 집밥(장보기) vs 외식 비율, 식재료 카테고리별 지출 |

## 끼니에 쓴 재료 → 냉장고 재고 자동 차감

1. 끼니를 추가하거나 수정할 때 **사용한 냉장고 재료**를 고르고 사용량을 적습니다. 재료는 여러 개 붙일 수 있고, 단위(g·ml·개)는 재료에 맞춰 자동으로 붙습니다.
2. 끼니를 **완료 체크**하면 연결한 재료의 남은 양이 사용량만큼 줄어듭니다. 0 아래로는 내려가지 않고, 0이 되면 그 재료는 자동으로 **소진** 처리됩니다.
3. **완료 취소·수정·삭제**를 하면 실제로 빠졌던 만큼만 정확히 재고로 되돌아옵니다. 중복 차감을 막기 위해 끼니마다 차감 상태와 차감량을 함께 기록합니다.

끼니 카드에는 `앞다리살 200g · 두부 150g`처럼 연결한 재료와 사용량이 작게 표시됩니다.

## 냉장고 재고: 총량 · 남은 양 · 구매일 · 구매처

- 재료마다 **총량과 단위**(g·kg·ml·L·개·봉·팩)와 **남은 양**을 적습니다. 카드에는 `남은 양 350g / 500g`과 진행 막대가 나옵니다.
- **구매일**과 **구매처**(쿠팡 · 네이버 · 지마켓 · 알리 · 동네마트 · 편의점, 직접 입력도 가능)를 적으면 카드에 `쿠팡 · 11/17 구매 · D+3`처럼 보관일수가 표시됩니다. 필요하면 **유통기한**도 적을 수 있고, 3일 이내로 남으면 색으로 알려 줍니다.
- 목록 위에서 **이름 검색**, **카테고리 칩**, **상태 칩(전체 · 보유만 · 소진만)** 을 함께 걸어 볼 수 있어 소진된 재료를 숨기거나 소진된 것만 모아 볼 수 있습니다. 고른 상태는 앱을 다시 열어도 그대로 남습니다.
- 재료를 누르면 수정 창이 열립니다. 남은 양·구매일·구매처를 고치거나 **삭제**할 수 있습니다.
- 규격만 적힌 예전 데이터는 `500g · 1개` → 500g, `300g · 2개` → 600g, `30구` → 30개, `1kg` → 1000g처럼 **자동으로 총량을 계산**해 채웁니다.

## 장보기 요약 — 구매처별 주문금액 · 집밥 vs 외식

- 맨 위 **구매처별 주문금액** — 위에서 고른 기간(주간·월간·연간)에 구매처별로 쓴 식품 금액만 카드로 모아 보여 줍니다. `◀ ▶`로 기간을 넘기면 그 기간 누적 금액으로 다시 계산됩니다. 낱건 내역(주문 카드·품목 행)은 넣지 않았고, 날짜가 없는 주문은 합계에서 빠지며 몇 건인지 안내합니다.
- 바로 아래 **집밥(장보기) vs 외식** 비율 막대와 금액 — 이번 기간 식비가 집밥 위주인지 외식이 많은지 한눈에 보입니다.
- 그 아래 **식재료 카테고리별 지출**(육류·계란, 채소·두부·과일, 간편·양념·면) 막대 그래프가 이어집니다.

## 가계부 — 수입 · 지출 · 파킹

`가계부` 탭은 식재료뿐 아니라 생활비 전체를 요약해 보여 주는 대시보드입니다. 낱건 목록은 **`지출 내역`** 탭에 있고, 거기서 `+ 내역 추가`로 넣거나 내역을 눌러 **수정·삭제**할 수 있습니다. 가계부 탭 아래쪽의 `+ 내역 추가` · `📝 지출 내역 보기` 버튼으로도 오갈 수 있습니다. 모든 내역은 위에서 고른 기간에 맞춰 집계됩니다.

**구분 3가지**

| 구분 | 분류 |
| --- | --- |
| 수입 | 수입 · 이자수익 |
| 파킹·저축 | 비상금 · 적금 *(지출 합계에 들어가지 않습니다)* |
| 지출 | 장보기 · 외식 · 소모품 · 핸드폰요금 · 티비인터넷요금 · 구독료 · 관리비 · 보험 · 대출 · 경조사비 · 의료비 · 교육비 · 기타 |

**입력 항목** — 날짜, 구분, 분류, 금액, 비고(예: 넷플릭스, 친구 결혼식), 지출일 때 결제수단(`우리카드` / `현대카드` / `국민카드` / `체크·현금·이체`), 카드일 때 할부(`일시불` / 2~12개월). 새 지출의 기본 결제수단은 `우리카드`이고, `체크·현금·이체`를 고르면 할부 칸이 숨습니다.

**상단 요약** — `총 지출(파킹 제외)` · `총 수입` · `저축·비상금 파킹` · `순현금흐름`과 **카테고리별 지출** 막대(금액·비율).
장보기는 냉장고 재고와 주문에서 자동으로 잡히므로, 같은 구매를 가계부에 또 적으면 두 번 잡힙니다.
`비상금 파킹` 카드에는 기간과 상관없는 **누적 잔액**이 나옵니다.

**이번 달 신카 청구 예정** — 지출은 실제 쓴 날짜로 적고, 결제수단에서 카드를 고르면 그 카드가 통장에서 빠질 금액을 따로 계산합니다.

- 맨 위에 **우리카드 · 현대카드 · 국민카드 3장 합계**(이번 달 청구 예정 총액, 사용자별 합계, 일시불·할부 이번 달 분, 다음 달 예상)가 나옵니다.
- 그 아래 **카드마다 한 칸씩** — 이번 달 청구 예정 금액, 정산 기간과 사용 건수, 일시불, 할부 이번 달 분(회차별 내역), 다음 달 예상, **카드별 정산 기간 설정**, **카드별 실제 청구액 보정·지우기**가 따로 있습니다. 카드마다 결제일이 달라도 각자 기간으로 계산합니다.
- 기본 정산 기간은 **전월 1일 ~ 전월 말일**이고, 카드마다 `정산 기간` 시작일·마감일을 바꿀 수 있습니다(예: 25일 ~ 24일).
- **일시불 전액 + 할부금**(총액 ÷ 할부개월, 사용한 달 다음 달부터 매달)을 합쳐 보여 줍니다.
- 이번 달에 쓴 카드 금액은 **다음 달(예상)** 줄에 따로 나옵니다.
- 카드사 청구서와 몇백 원 차이가 날 수 있어 **실제 청구액 보정** 칸에 청구서 금액을 적으면 그 금액으로 보여 주고, 계산액과의 차이를 함께 표시합니다. `지우기`를 누르면 계산액으로 돌아갑니다.
- 예전에 `신용카드` 하나로 적어 둔 내역은 **`신용카드(미지정) · 기존`** 칸에 모여 3장 합계에 그대로 더해집니다(그런 내역이 있을 때만 칸이 보입니다). 내역을 눌러 카드를 골라 주면 그 카드 칸으로 옮겨집니다.

**사용자 구분 (나 · 배우자 · 공용)** — 내역마다 누가 쓴 건지 고를 수 있습니다. 목록에는 `배우자`·`공용` 배지가 붙고, 총 지출과 신카 청구 카드에 `나 00원 · 배우자 00원 · 공용 00원`처럼 사용자별 합계가 함께 나옵니다. 내역 목록 위의 칩으로 사람별로 걸러 볼 수 있습니다.
이름은 요약 카드의 **✏️ 이름** 버튼에서 바꿀 수 있고, 바꾼 이름은 기기(localStorage)에 저장되며 백업 JSON의 `userLabels`에도 함께 담깁니다.

## 내 데이터 불러오기 · 합치기 · 백업

상단의 **📥 불러오기 · 📤 백업** 버튼을 누르면 데이터 창이 열립니다.

- **➕ 기존 데이터에 합치기** — JSON 파일이나 붙여넣은 내용 중 `orders · inventory · meals · shopping · ledger · userLabels`에 들어온 항목만 기존 기록에 더합니다. 같은 주문·같은 품목·같은 날 같은 끼니·같은 가계부 내역은 건너뜁니다. 날짜가 없는 항목은 오늘 날짜로 들어갑니다.
- **전체 복원 (덮어쓰기)** — 백업 JSON으로 지금 데이터를 통째로 바꿉니다.
- **백업하기** — `파일로 내려받기`로 JSON을 저장하거나 `JSON 텍스트 복사`로 복사해 둡니다.
- 불러온 데이터는 그 브라우저에만 저장되고 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 함께 사라지니 백업 파일을 따로 보관하세요.

### 데이터 파일 형식 (v3)

```json
{
  "app": "our-home-table",
  "v": 3,
  "exportedAt": "2026-11-18T22:00:00+09:00",
  "servings": 2,
  "data": {
    "cursor": "2026-11-18",
    "period": "week",
    "orders": [],
    "meals": {
      "2026-11-17": [
        {
          "id": "2026-11-17-0",
          "slot": "저녁",
          "menu": "앞다리살 김치찌개",
          "done": true,
          "items": [{ "invId": "i1", "name": "앞다리살", "qty": 200, "appliedQty": 200 }],
          "applied": true
        }
      ]
    },
    "inventory": [
      {
        "id": "i1",
        "name": "앞다리살",
        "spec": "500g",
        "price": 8820,
        "cat": "육류·계란",
        "from": "쿠팡",
        "src": "manual",
        "date": "2026-11-17",
        "exp": "",
        "totalQty": 500,
        "remainQty": 300,
        "unit": "g",
        "used": false,
        "usedDate": ""
      }
    ],
    "shopping": [],
    "ledger": [
      {
        "id": "e1",
        "date": "2026-11-15",
        "kind": "expense",
        "cat": "구독료",
        "who": "me",
        "amount": 17000,
        "memo": "넷플릭스",
        "pay": "card",
        "inst": 0
      }
    ],
    "cardCfg": { "start": 1, "end": 0 },
    "cardAdj": { "2026-11": { "amount": 412300, "memo": "" } },
    "userLabels": { "me": "나", "partner": "배우자", "shared": "공용" },
    "dedupe": true
  }
}
```

- `meals`는 `YYYY-MM-DD` 날짜 키의 배열입니다. `slot`은 아침·점심·저녁·간식·야식, `menu`는 메뉴 이름입니다. `items`는 그 끼니에 쓴 재료(`invId`·`name`·`qty`)이고, `applied`·`appliedQty`는 완료 체크로 재고가 빠진 상태와 실제 빠진 양을 기록합니다.
- `inventory`의 `totalQty`·`remainQty`·`unit`은 총량·남은 양·단위입니다. 값이 없으면 `spec`에서 자동으로 계산합니다. `date`는 구매일, `from`은 구매처, `exp`는 유통기한, `usedDate`는 소진일입니다.
- `orders`의 `date`로 기간별 집계에 들어갑니다. 주문에 `"store": "네이버"`를 적으면 장보기 요약에서 그 구매처로 묶입니다(없으면 쿠팡).
- `ledger`의 `kind`는 `income`·`save`·`expense`, `cat`은 위 분류 중 하나, `who`는 `me`·`partner`·`shared`, `pay`는 `woori`(우리카드)·`hyundai`(현대카드)·`kb`(국민카드)·`cash`(체크·현금·이체)이고 예전 `card`(신용카드 미지정)도 그대로 읽습니다. `inst`는 할부 개월(0이면 일시불)입니다.
- `cardCfg`는 카드별 정산 기간(`{"woori":{"start":1,"end":0}, …}` — `end` 0은 말일, 예전 `{"start":1,"end":0}` 한 벌도 카드 모두에 같이 적용), `cardAdj`는 달마다 카드별로 직접 적은 실제 청구액(`{"2026-11":{"woori":123000}}`, 예전 `{amount, memo}`는 `card` 자리로)입니다.
- `userLabels`는 가계부에 보이는 사용자 이름입니다.
- 예전 형식(`weekStart` + `text` 메뉴 키, 요일 이름 키, 날짜 없는 7칸 배열, `offline` 장보기 기록)도 불러올 때 오류 없이 처리합니다. `offline` 기록은 냉장고 재고로 통합되어 건너뜁니다.
- `data` 안의 `orders · meals · inventory · shopping · ledger · userLabels` 중 일부만 있어도 **합치기**로 더할 수 있습니다.
- 화면의 `장볼 목록` 탭은 없어졌지만, 예전에 저장한 `shopping` 데이터와 백업 파일의 `shopping` 항목은 그대로 읽고 보관합니다(데이터 손실 없음).

## GitHub Pages로 열기

3. 잠시 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.
