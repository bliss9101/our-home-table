# 우리집 식탁 · 주간 식단 · 장보기

주간 식단 체크, 냉장고 재고, 장볼 목록, 가계부, 쿠팡 주문 요약을 한 페이지에서 보는 모바일용 HTML 한 장입니다.
빌드 도구도, 서버도, 외부 스크립트도 쓰지 않습니다. `index.html` 파일 하나로 동작합니다.

## 이 저장소에 들어 있는 것

- `index.html` — **빈 템플릿**입니다. 주문·재고·식단 같은 개인 데이터가 들어 있지 않고, 화면은 0원 · 0품목 · 0끼 상태로 열립니다.
- 데이터는 **이 저장소에 올리지 않습니다.** 각자 기기에서 아래 방법으로 불러오면 브라우저(localStorage)에만 저장됩니다.

## GitHub Pages로 열기

1. 이 폴더를 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)` 또는 이 폴더로 지정합니다.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

## 내 데이터 불러오기 / 백업하기

상단의 **📥 불러오기 · 📤 백업** 버튼을 누르면 데이터 창이 열립니다.

- **불러오기** — 백업 JSON 파일을 올리거나, JSON 내용을 붙여넣고 `불러오기`를 누릅니다.
- **백업하기** — `파일로 내려받기`로 JSON을 저장하거나 `JSON 텍스트 복사`로 복사해 둡니다.
- 불러온 데이터는 그 브라우저에만 저장되고 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 함께 사라지니 백업 파일을 따로 보관하세요.

### 데이터 파일 형식

```json
{
  "app": "our-home-table",
  "v": 1,
  "exportedAt": "2026-11-16T22:00:00+09:00",
  "data": {
    "weekStart": "2026-11-16",
    "orders": [],
    "meals": {},
    "inventory": [],
    "shopping": [],
    "offline": [],
    "dedupe": true
  }
}
```

`data` 안의 `meals · inventory · shopping · offline · orders` 중 하나만 있어도 불러올 수 있습니다.

## 참고

- 외부 요청, 분석 도구, 쿠키를 쓰지 않습니다.
- 금액 계산은 모두 페이지 안에서만 이루어집니다.
