# 우리집 식탁 · 주간 · 월간 · 연간 식단 · 장보기

주간/월간/연간으로 넘겨 보는 식단 달력, 냉장고 재고, 장볼 목록, 가계부, 쿠팡 주문 요약을 한 페이지에서 보는 모바일용 HTML 한 장입니다.
빌드 도구도, 서버도, 외부 스크립트도 쓰지 않습니다. `index.html` 파일 하나로 동작합니다.

## 이 저장소에 들어 있는 것

- `index.html` — **빈 템플릿**입니다. 주문·재고·식단 같은 개인 데이터가 들어 있지 않고, 화면은 0원 · 0품목 · 0끼 상태로 열립니다.
- 데이터는 **이 저장소에 올리지 않습니다.** 각자 기기에서 아래 방법으로 불러오면 브라우저(localStorage)에만 저장됩니다.

## 기간 보기 (주간 · 월간 · 연간)

화면 위쪽의 `주간 | 월간 | 연간`으로 보기를 바꾸고, `◀` · `이번 주/이번 달/올해` · `▶`로 기간을 옮깁니다.

- **주간** — 월~일 7일 식단 카드, 주간 진행률, 주간 지표(구매액·재고·끼니·끼니당/1인당 평균 식대)
- **월간** — 월 달력(날짜마다 등록·완료 끼니 표시). 날짜를 누르면 그날 식단을 바로 확인·추가·수정할 수 있고, 월 구매액·소진비용·완료 끼니·끼니당 평균 식대와 카테고리별 지출이 함께 나옵니다.
- **연간** — 1~12월 월별 구매액·소진비용 막대 그래프와 연간 합계(총 구매비용·총 소진비용·완료 끼니·월 평균 식비)

가계부 탭과 장보기 요약 탭의 숫자도 위에서 고른 기간에 맞춰 다시 계산됩니다.

## 내 데이터 불러오기 · 빠른 추가 · 백업

상단의 **📥 불러오기 · 📤 백업** 버튼을 누르면 데이터 창이 열립니다.

- **⚡ 빠른 추가 (기존 데이터에 합치기)** — 영수증·마트 사진으로 만든 JSON 조각을 붙여넣고 누르면 `orders · inventory · meals · shopping · offline` 중 들어온 항목만 기존 기록에 더합니다. 같은 주문·같은 품목·같은 날 같은 끼니는 건너뜁니다. 날짜가 없는 항목은 오늘 날짜로 들어갑니다.
- **전체 복원 (덮어쓰기)** — 백업 JSON으로 지금 데이터를 통째로 바꿉니다.
- **백업하기** — `파일로 내려받기`로 JSON을 저장하거나 `JSON 텍스트 복사`로 복사해 둡니다.
- 불러온 데이터는 그 브라우저에만 저장되고 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 함께 사라지니 백업 파일을 따로 보관하세요.

### 데이터 파일 형식 (v2)

```json
{
  "app": "our-home-table",
  "v": 2,
  "exportedAt": "2026-11-16T22:00:00+09:00",
  "servings": 2,
  "data": {
    "cursor": "2026-11-16",
    "period": "week",
    "orders": [],
    "meals": {
      "2026-11-16": [
        { "id": "2026-11-16-0", "slot": "아침", "menu": "계란 토스트", "done": false }
      ]
    },
    "inventory": [],
    "shopping": [],
    "offline": [],
    "dedupe": true
  }
}
```

- `meals`는 `YYYY-MM-DD` 날짜 키의 배열입니다. `slot`은 아침·점심·저녁·간식·야식, `menu`는 메뉴 이름입니다.
- `orders`·`offline`은 `date`(`YYYY-MM-DD`)로 기간별 집계에 들어갑니다. `inventory`의 `date`는 구매일, `usedDate`는 소진일입니다.
- 예전 형식(`weekStart` + `text` 메뉴 키, 요일 이름 키, 날짜 없는 7칸 배열)도 불러올 때 자동으로 날짜 키 구조로 바꿉니다.
- `data` 안의 `orders · meals · inventory · shopping · offline` 중 일부만 있어도 **빠른 추가**로 합칠 수 있습니다.

### 빠른 추가 예시

```json
{
  "offline": [
    { "date": "2026-11-16", "store": "동네마트", "name": "사과 3개", "cat": "채소·두부·과일", "amount": 3900, "qty": 3 }
  ],
  "inventory": [
    { "name": "사과", "spec": "3개", "price": 3900, "cat": "채소·두부·과일", "date": "2026-11-16" }
  ],
  "meals": {
    "2026-11-18": [{ "slot": "저녁", "menu": "김치찌개" }]
  }
}
```

## GitHub Pages로 열기

1. 이 폴더를 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)` 또는 이 폴더로 지정합니다.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.
